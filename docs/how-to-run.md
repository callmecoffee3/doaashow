# How to Run

## HTML prototypes
Open any `.html` file directly in a modern browser.

## Batch menus (Windows)
Double-click or run from Command Prompt:
- `DOASHOW - UPDATED.bat` (main launcher)
- Various `thefam*.bat`, `shopping*.bat`, game `.bat` files

## Recommended entry points (after cleanup)
- Desktop → `01-core/desktop/`
- The Fam → `02-the-fam/`
- Production tools → `03-production/`

More detailed instructions will be added as the structure is populated.
