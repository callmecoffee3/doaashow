# Film Projects

Each new production should be copied from the `_TEMPLATE` folder.

## How to start a new project

1. Copy the entire `_TEMPLATE` folder
2. Rename it to your project name (example: `The-Rise-of-King-God`)
3. Start putting files into the correct stage folders

## Folder Pipeline

- **01-Development** → Ideas, scripts, treatments, pitch decks
- **02-Pre-Production** → Storyboards, schedules, casting, locations, budget
- **03-Production** → Raw footage, production audio, stills, on-set notes
- **04-Post-Production** → Edit, VFX, color, sound design, music
- **05-Delivery** → Final masters, trailers, promos, subtitles, archive
- **Assets** → Shared graphics, fonts, references, legal docs
