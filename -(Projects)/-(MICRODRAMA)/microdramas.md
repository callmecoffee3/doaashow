## How to use

1. Open **Workspace** → select or create a **Project**
2. Create **Decks** inside the project
3. Add **Index Cards** (Characters, Scenes, Props, Animals, Prompts)
4. Go to **AI Studio**
5. Optionally check **“Include active project cards in generation”**
6. Write a prompt (or leave blank to use the Core Hook)
7. Generate your micro drama
