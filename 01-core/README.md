# 01-core

The heart of doaashow.

## Subfolders

- **desktop/** — Main simulated desktop environment (windows, taskbar, icons, React/HTML experiments)
- **os-shell/** — DOS-style batch menus and primary launchers (`DOASHOW - UPDATED.bat`, etc.)
- **cloudos/** — Cloud OS / web-based OS experiments (`cloudos.html` and related)

New desktop and shell work should live here.
