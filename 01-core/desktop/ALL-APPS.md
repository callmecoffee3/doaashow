# All apps

This catalog contains **171 apps** for the desktop and app launcher. It combines the master app list in the OS notes with the apps added to the current desktop, including Settings, Options, Notes, Scheduler, AI, Video Generator, Ideas, Characters, Movie, Plot, Email, Live Share, Windows Player, Main Show, Show Name, App Store, Stores, Shops, Malls, Shopping List, Podcast, Plays, Poster Board, User Feed, Group, Account, Sticky Notes, Teacher, and Student.

**Launcher requirements:** The App Store should be scrollable, include search, and organize apps by category. Start search should include a **Quick Links** menu for fast access to pinned, favorite, and recently used apps.

**Catalog maintenance:** Always update this main All Apps file whenever an app is added, renamed, removed, or moved to another category. Keep the app total, description, ID, and default status synchronized with the desktop.

**Desktop update reminder:** After every change to this catalog, update the desktop so its launcher, App Store, Settings, categories, shortcuts, and app total match the All Apps file.
