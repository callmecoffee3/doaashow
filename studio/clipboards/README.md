# Dashboards

At-a-glance status of everything on the lot. What's in development, what's shooting, what's in post, what's delivered.

## Boards

| Dashboard | What it tracks | Source |
|---|---|---|
| Production status | Active productions and their stage | `../../projects/`, `../../PRODUCTIONS.md` |
| Shows | Series and show development | `../../03-production/shows/` |
| Development slate | Treatments and ideas in the pipeline | `../../03-production/pre-production/` |
| Asset inventory | Video, audio, images, props on hand | `../../05-assets/` |
| Studio memory | Projects, stories, characters, scenes | `../../memory/` |

New productions get a row here the day they're greenlit on the [front lot](../front-lot/).
