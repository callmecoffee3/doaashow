# Back Lot — Sets, Stages & Production

Where the shooting happens. Soundstages, sets, props, characters, and everything the cameras capture.

## What's here

| Stage / Department | Folder | Contents |
|---|---|---|
| Sets & scenes | `../../03-production/scenes/`, `../../05-assets/scenes/` | Scene work and set assets |
| Props | `../../05-assets/props/` | Prop assets |
| Characters | `../../03-production/characters/`, `../../05-assets/characters/` | Character development and assets |
| Footage | `../../05-assets/video/` | Video assets |
| Audio | `../../05-assets/audio/` | Sound assets |
| Images & icons | `../../05-assets/images/`, `../../05-assets/icons/` | Stills and graphics |
| Finished productions | `../../projects/` | Rapture: After the Trumpet, ReelWave |
| Production memory | `../../memory/` | Scenes, sounds, videos, characters, messages, pages |

## How it works

Productions come over from the [front lot](../front-lot/) with a script and a checklist, shoot on the back lot, and wrap into `../../projects/` as finished work. Every production leaves with an opener and a closer — house rule.
