# Systems

Technical experiments and platform tools for DoaShow.

- **Desktop/** — Simulated desktop, OS-like interfaces, UI experiments
- **Menus/** — All menu systems and batch menu files
- **Terminals/** — Terminal-style interfaces (thefam, doashow terminals)
- **File-Tools/** — Folder scanners, file browsers, uploaders
- **Apps/** — Small tools, bots, games, utilities
