# Project Template

Copy this entire folder and rename it for each new film/TV project.

## Pipeline

1. **01-Development** — Concept, Scripts, Treatments, Pitch Materials
2. **02-Pre-Production** — Storyboards, Shot Lists, Schedules, Casting, Locations, Budget
3. **03-Production** — Footage, Audio-Raw, Stills, On-Set-Notes
4. **04-Post-Production** — Edit, VFX, Color, Sound-Design, Music
5. **05-Delivery** — Final-Masters, Trailers, Promos, Subtitles, Archive
6. **06-Assets** — Graphics, Fonts, References, Legal
