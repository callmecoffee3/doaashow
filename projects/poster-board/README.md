# Poster Board

A private server-backed poster board app (React client + TypeScript server + SQLite via Drizzle) with a public notices wall and a private "Just me" area.

## Key files

- `client/src/App.tsx` — app UI
- `server/src/actions.ts`, `server/src/schema.ts` — backend logic and data model
- `drizzle/` — database migrations
- `package.json`, `space.json` — project config
