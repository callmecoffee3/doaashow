This is my experimental desktop environment / playground.

> For entertainment purposes.  
> Just for goofing off.

---

### What is this?

A growing collection of desktop-related experiments:

- Custom desktop layouts and screens
- Taskbar, sidebars, drawers, and navigation ideas
- File explorer concepts
- Window management experiments
- Clock, date, and system UI pieces
- Social, media, and messenger mockups
- An `os/` folder for deeper operating system experiments
- Integration points with **doashow**
- **Settings** and **Options** panels for configuring the desktop experience

Basically: what if I built my own desktop environment just for fun?

---

### Settings & Options

The `Settings` and `Options` folders are where configuration lives:

- **Settings** → Core desktop behavior (theme, layout, performance, system preferences)
- **Options** → Optional features and user toggles (experimental stuff you can turn on/off)

These areas are still evolving as the desktop grows.

---

### Philosophy

Move fast. Break things. Keep the ideas that feel good.

This repo is a sandbox. Not everything has to be finished or perfect. The goal is to explore desktop interfaces, OS concepts, and how they can connect to creative tools like doashow.
