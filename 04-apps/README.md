# 04-apps

Standalone tools and experimental apps.

## Subfolders

- **folder-scanner/** — Folder / file scanner tools
- **shopping/** — Shopping list and related tools
- **games/** — Games (zombie game, virus simulator, etc.)
- **mall-stores/** — 300stores mall directory experiments
- **utilities/** — Token maker, prediction tools, etc.
- **the-fam-apps/** — Apps related to The Fam social network (from 02-the-fam)

## App Categories (for the simulated desktop)

When apps appear in the Start Menu / App Store they use these categories:

- Main Core
- Health
- Medical
- Law
- Home
- Entertainment
- Library
- **Life** (includes The Fam)
- Law & Government
- Exploration
- Production
- Transportation
- Genres
- Special Effects (SFX)
- Series
- Data
- Reality
- Tools
- Commerce
- Settings / Options / Help

**The Fam** (folder 02) apps and features are treated as part of the **Life** category and also have their own dedicated space under `the-fam-apps/`.
