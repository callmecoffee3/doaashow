# the-fam-apps

Apps and tools related to **The Fam** social network (from `02-the-fam`).

This folder holds standalone or experimental apps that connect to or extend The Fam experience (feeds, messenger, profiles, terminals, etc.).

Main The Fam structure still lives in:
- `02-the-fam/terminal/`
- `02-the-fam/bat/`
- `02-the-fam/feed/`
- `02-the-fam/messenger/`
- `02-the-fam/profiles/`
