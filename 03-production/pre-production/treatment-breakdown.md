## How they flow together

```
Idea Treatment  →  Classic Stages  →  Prose / Index-Card / Writer-Area
                                              ↓
                                    Contact Treatment (crew & talent)
                                              ↓
                                    Production Treatment (active make)
                                              ↓
                                    Finished work → shows / scenes / characters
```

1. **Idea Treatment** — something sparks. Capture it before it evaporates.
2. **Classic Stages** — walk the idea through the standard writing path.
3. **Prose / Index-Card / Writer-Area** — develop structure and voice in the form that fits you.
4. **Contact Treatment** — assign people (even if imaginary) to roles.
5. **Production Treatment** — when you’re actually making the thing.
6. Move finished pieces into `shows/`, `scenes/`, `characters/`, `story-tools/`.

---

## When to use which one

| Situation | Start with |
|-----------|------------|
| Brand new idea just hit | **Idea Treatment** |
| Want a clear path from idea to locked | **Classic Stages** |
| Prefer writing a short narrative outline | **Prose Treatment** |
| Prefer visual / card-based structure | **Index-Card Treatment** |
| Need a living workspace for the story | **Writer-Area Treatment** |
| Need names and contacts for the team | **Contact Treatment** |
| Cameras / code / recording are rolling | **Production Treatment** |
