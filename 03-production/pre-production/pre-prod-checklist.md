# Pre-Production Checklist

Use this before you start building a show, scene, or game inside doaashow.

---

## Concept

- [ ] Working title
- [ ] One-sentence logline
- [ ] Genre / vibe locked (or intentionally messy)
- [ ] Format decided (microdrama, full episode, game, radio, etc.)

## Story

- [ ] Treatment or short synopsis written
- [ ] Beginning / middle / end (or open-ended structure) clear
- [ ] At least one strong conflict or hook

## Characters

- [ ] Main characters named and roughly described
- [ ] Character sheets started (in `../characters/` when ready)
- [ ] Voice / dialogue style noted

## World

- [ ] Setting / location notes
- [ ] Any special rules of the universe written down
- [ ] Visual / audio references collected (links or lists)

## Production readiness

- [ ] Scene breakdown or beat sheet exists
- [ ] Assets needed listed (images, audio, video, icons)
- [ ] Target folder decided (`shows/`, `scenes/`, `story-tools/`, etc.)
- [ ] Fun factor still high ☕

---

When most boxes are checked, move the solid pieces out of pre-production and start building.
