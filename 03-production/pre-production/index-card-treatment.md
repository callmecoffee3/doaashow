# Index Card Treatment

Beat-by-beat structure using the classic index-card method.  
One card = one beat / scene / sequence. Keep each card short and clear.

**Project / Working Title:**  
**Format:** (movie / TV episode / game level / podcast episode / theatre act / other)  
**Status:** idea / outlining / locked for writing

---

## How to use

1. Write one short beat per card (goal, conflict, or turn).
2. Number them in order.
3. Color-code or tag if you want (e.g. A-story, B-story, action, emotion).
4. Move cards around until the spine feels right.
5. Expand the strongest cards into full scenes later.
