## 12. Post-production handoff checklist

When this unit is “in the can”:

- [ ] All takes / builds captured
- [ ] Selects marked or noted
- [ ] Sound / audio organized
- [ ] Continuity / notes attached
- [ ] Assets named and stored in `05-assets/` (or show folder)
- [ ] Production treatment updated to “Done” for this unit
- [ ] Ready for edit / assembly / polish

## How this relates to pre-production

| Stage | Where it lives |
|-------|----------------|
| Ideas → Locked treatment | `pre-production/` |
| **Active production** | **This file** (`production-treatment.md`) |
| Finished shows / scenes / characters | `shows/`, `scenes/`, `characters/`, `story-tools/` |

Keep this document alive while you’re making the thing. Update status columns often. When a unit is finished, move polished results into the proper production folders and mark it done here.
