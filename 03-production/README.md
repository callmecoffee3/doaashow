## Pages / Sections

| Section | Purpose |
|---------|--------|
| [**Pre-Production**](pre-production/) | Ideas, treatments, index cards, writer area, contact sheets, classic writing stages, full crew lists |
| [**Production Treatment**](production-treatment.md) | **Active production document** — schedule, scene status, cast/crew for the current make, shot lists, daily log |
| [**Shows**](shows/) | Individual show projects |
| [**Characters**](characters/) | Character definitions and ideas |
| [**Scenes**](scenes/) | Scene ideas and scripts |
| [**Story Tools**](story-tools/) | Writers, playbill, scene generators, act structures |

---

## Workflow

1. **Plan** in `pre-production/` (ideas → stages → locked treatment + crew)
2. **Make** using the [Production Treatment](production-treatment.md)
3. **Store finished pieces** in `shows/`, `scenes/`, `characters/`, `story-tools/`
4. Assets go to `05-assets/` when ready
