# Trash

Soft-delete zone for DoaShow.

Nothing here is permanently gone.  
Files land here when they already have an **official home** in Production, Systems, or Assets.

## Rules

1. **Do not put unique/original work here** until a copy exists in the structured folders.
2. Root originals that were copied into Systems/Production can be staged here.
3. Empty this folder later only after you confirm everything still works.
4. Prefer this over hard-deleting from the repo.

## Layout

```
Trash/
├── from-root/          ← loose root files that were migrated
├── from-projects/      ← old -(Projects) placeholders if archived
└── INDEX.md            ← full list of staged items
```

## Official homes (do not trash these)

- `Production/` — living creative core
- `Systems/` — menus, apps, desktop, terminals, tools
- `Assets/` — shared media
- `Legacy/` — long-term archive indexes
