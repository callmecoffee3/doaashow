# 02-the-fam

Social network simulation — **The Fam**.

## Subfolders

- **terminal/** — The Fam terminal UIs (`thefamterminal*.html`)
- **bat/** — Batch launchers (`THE FAM.bat`, `thefam*.bat`, etc.)
- **feed/** — Feed / post related
- **messenger/** — Messaging experiments
- **profiles/** — User / character profiles

Key files are being organized into these folders over time.
