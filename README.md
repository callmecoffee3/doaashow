# DoaShow

**Professional Media Production System**

something to play with for creating media like movies, tv shows, games and stuff — now organized like a real production company.

---

## Production Structure

Everything lives under `-(Projects)/Production/`

```
Production/
├── Categories/          → Genres & formats
├── Schools/             → School universe (students, teachers, classes, cafeteria…)
├── Roles/               → Full professional film crew
└── Film-Projects/       → Actual shows & series with full pipelines
```

### Categories
Action · Adventure · Animation · Comedy · Documentary · Drama · Experimental · Horror · Media · Microdrama · News-Media · Reality · Sci-Fi · Shorts

### Schools
Cafeteria · Classes · Students · Teachers · Activities

### Roles (Crew)
**Creative** — Director, Assistant Director, Executive, Producers, Line Producer, Writers  
**Camera** — Director of Photography, Camera Operator, Gaffer, Key Grip  
**Sound** — Sound Mixer, Boom Operator  
**Art** — Production Designer, Art Director, Costume Designer, Makeup Artist, Hair Stylist  
**Post** — Editor, Colorist, VFX Supervisor, Composer  
**Support** — Script Supervisor, Production Manager, Casting Director, Location Manager, Stunt Coordinator, Production Assistant

### Film Projects
Each project follows a real production pipeline:

1. **Development** — Concept, Scripts, Treatments, Pitch Materials  
2. **Pre-Production** — Storyboards, Shot Lists, Schedules, Casting, Locations, Budget  
3. **Production** — Footage, Audio, Stills, On-Set Notes  
4. **Post-Production** — Edit, VFX, Color, Sound Design, Music  
5. **Delivery** — Final Masters, Trailers, Promos, Subtitles, Archive

---

## How to start a new project

1. Go to `-(Projects)/Production/Film-Projects/`
2. Copy the `_TEMPLATE` folder
3. Rename it to your project name
4. Start working in the correct stage folders
